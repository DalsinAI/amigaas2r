# AS2R: Another Sonic 2 Remake for AmigaOS 3

Reproducible content-port tooling for running **AS2R: Another Sonic 2 Remake**
with the shared [Amiga OpenSurge](https://github.com/DalsinAI/amigaopensurge)
engine. This repository does not fork the engine or its graphics stack.

## Upstream

- Showcase: <https://sonicfangameshq.com/forums/showcase/as2r-another-sonic-2-remake-sage-22-demo.1389/>
- Expected archive SHA-256: `dd79b04d12164ff5572a0abed1f38930e3d102d498d9113f82aed00a3a9eece2`
- Expected extracted directory: `Another Sonic 2 Remake`
- Original engine: OpenSurge 0.6.0.1 / Allegro 5.2.7-1

The downloadable package contains complete OpenSurge GPLv3 engine source, but
the showcase does not grant clear redistribution permission for all bundled
game assets. Therefore this repository publishes the port recipe and metadata,
not the upstream archive or a repackaged game.

## Prepare a local port

```sh
./scripts/prepare-amiga-port.sh \
  "/path/to/Another Sonic 2 Remake" \
  ./dist/AS2R
```

Install the QPAK-enabled shared engine at `DH1:OpenSurgeRC1`, then run the
prepared port with `Execute DH1:AS2R/StartGame`. This uses OpenSurge's `--game`
compatibility path rather than copying or forking the engine.

See [PORT_STATUS.md](PORT_STATUS.md) for validation results.

## Standalone release (engine included)
`AS2R-AmigaOS3-standalone-rc1.lha` is the Amiga OpenSurge engine, ready to
play AS2R: Another Sonic 2 Remake: the AS2R drawer with the engine inside it, `StartGame`,
GlowIcons, `Install-AS2R`, the ReadMe and the licences. **It contains none
of the game's own files**: the player downloads the game from its page
themselves, and `Install-AS2R` builds the game drawer from that download on
the Amiga, beside the bundled engine. No separate engine install is needed.

`Install-AS2R` (AmigaOS Installer 43.3+) checks the CPU, FPU and GFOpenGPU,
copies the AS2R drawer to the chosen place (Work:Games is offered), then asks
for the player's own copy of the game:
- the downloaded archive `Another Sonic 2 Remake Android Compatible.zip`: its size must be
  121434129 bytes; it is unpacked with AmiCradle's
  `SYS:Utilities/GFOpenCompress`;
- or the folder `Another Sonic 2 Remake` that unpacking it made: its name and the sizes
  of three of its files are checked;
- or a `game.zip` made on another computer with `scripts/prepare-amiga-port.sh`.

The game's files are copied into `AS2R/Game` without the Windows program
files and with the same `MenuButtonList` and `surge.cfg` changes the prepare script makes (`port/PatchMenu.rexx`, run with ARexx).
A SHA-256 check of the archive is left to the player (the ReadMe gives the
value): AmigaOS has no SHA-256 tool, so the Installer checks sizes.

The engine inside is [DalsinAI/amigaopensurge](https://github.com/DalsinAI/amigaopensurge)
release `v0.6.1.3-amigaos3-rc3` at commit
[`f07fe8a`](https://github.com/DalsinAI/amigaopensurge/tree/f07fe8aa91f6a14c2c79ba00757b85ac40c693fb)
(GFOpenAmigaGCC 16.2.0-open5 rebuild): asset
`opensurge-0.6.1.3-amigaos3-68040-rc3.tar.gz`, SHA-256
`61b569557e8d83a17ac794d0229d3bf0792cc58d4304c54e3ca1745ceae3f4c8`; `dist/opensurge`
`f2ed2503a012b062fb933df1e97bfccccbdef86809e2214b3f502685280f6511`. `port/engine.env`
pins it and `scripts/package-standalone.sh` refuses any other bytes.

Build the archive (Linux, Python 3; the engine asset is fetched with `gh` when
`-e` is not given):

```sh
./scripts/package-standalone.sh [-e opensurge-0.6.1.3-amigaos3-68040-rc3.tar.gz] ./dist
```
No game file is needed, read or packed. Files are stamped with the commit
time and written in a fixed order, so the same inputs give the same archive
bytes.

`port/` holds what goes in the drawer: `StartGame`, `Install-AS2R` and
`icons/*.info` are generated by `tools/make_installer.py` from
`port/installer.json` and `port/icons/icons.json` with a checkout of
DalsinAI/amicradle (`scripts/port_installer.py`, `scripts/port_icons.py`), and
committed. `tools/lha_archive.py` is AmiCradle's LhA writer.

### The shared-engine route

The earlier route still works: `scripts/prepare-amiga-port.sh` makes `game.zip`
and a `StartGame` (`port/StartGame.shared`) for a shared engine installed at
`DH1:OpenSurgeRC1`. The standalone archive replaces it for players.
